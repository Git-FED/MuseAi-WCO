# How it works

1. Find a claim in a permitted public source.
2. Record the canonical name, category, status, date, and source.
3. Verify material events on a second surface where possible.
4. Keep detailed notes in the private tier.
5. Generate the redacted public tier with the script.
6. Publish or open only the public map; never expose the private CSV through the map.
7. Track mirror relationships as follow-up events, not as access instructions.
