# Tracker rules

- Records only; no speculation.
- Preserve `UNVERIFIED` and conflicting-source labels.
- No live links in public output.
- Do not visit, stream from, download from, or test a service for use.
- The public map reads public data only.
- Append rename and mirror observations; never overwrite history.
- Separate a brand from an unrelated clone unless continuity is established.
